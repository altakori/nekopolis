# Playable 3D v2 Implementation Plan

> **For Hermes:** Implement and verify task-by-task; the shared simulation remains the only source of gameplay truth.

**Goal:** Replace the static Three.js comparison scene with a fully playable 3D surface that supports every player-facing rule and action available in the 2D game.

**Architecture:** Keep `src/simulation.ts` unchanged as the canonical state machine. `src/v2.ts` owns 3D raycast input, scene synchronization, an independent but schema-compatible autosave, and DOM UI. `src/v2-scene.ts` owns terrain/facility/utility meshes so presentation stays separate from state mutation.

**Tech Stack:** TypeScript, Three.js, Vite, existing simulation functions, Playwright/installed Chrome for browser QA.

---
