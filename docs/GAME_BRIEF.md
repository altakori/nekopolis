# 냥토피아 공업구역 (Nekopolis Foundry)

## 한 줄 콘셉트
고양이 시민을 위한 캣닢·사료·가구 생산망, 외부 도로, 직선 전력·상수도 인프라를 직접 설계하는 2.5D 공장도시 건설 웹게임.

## 핵심 경험
- 20×14 도시 위에 건물·농장·도로를 배치하고, 전선·수도관은 타일과 시설을 관통하는 직선 segment로 잇는다.
- 발전소→전선→시설, 취수장→정수장→수도관→시설의 연결 상태가 실제 생산을 결정한다.
- 캣닢 밭이 원료를 만들고 사료 공장과 가구 공장이 자원을 가공한다.
- 전력·정수·서쪽 외부도로가 연결된 숙소가 고양이를 이주시키며, 실제 인구가 총 노동력을 결정한다.
- 고양이 회관 레벨이 최대 고양이 수를 결정하며 업그레이드에는 전력·물·노동·코인이 필요하다.
- 기반선, 첫 수확, 정착, 자립 지구의 순차 계약으로 다음 건물을 영구 해금한다.
- 시민은 매 교대 사료를 실제 소비하며, 플레이어는 식량·재료·균형 중 노동 우선순위를 선택한다. 정수 인프라를 먼저 배정하고 같은 종류 시설은 교대별 round-robin으로 기회를 나눈다.
- 사료·가구 공방의 부산물을 재활용해 목재로 되돌리고, 캣닢 찻집과 황혼 배송으로 생활 경제를 운영한다.

## 자원
코인, 전력, 물, 캣닢, 사료, 목재, 가구, 부산물, 현재 고양이, 최대 고양이, 가용 노동력, 행복도.

## 건설 요소
도로, 전선, 수도관, 캣닢 밭, 혼합 농장, 발전소, 취수장, 정수장, 사료 공장, 가구 공방, 재활용 공방, 캣닢 찻집, 숙소, 고양이 회관, 캣타워 광장.

## 화면 방향
황혼의 강변 개척 공업도시를 하나의 제품 언어로 표현한다. 지도는 화면의 주인공이며, 짙은 청록 command bar와 금속성 하단 건설 dock이 이를 보조한다. 청록은 전력, 파랑은 물, 황색은 목표/생산, 주황은 선택/경고에만 사용한다. 현재 계약, 추천 건설, 지도 상태 표식, context inspector가 같은 원인을 설명해야 한다.

## 진행 계약
1. 강변 기반선: 발전소·취수장·정수망을 가동해 농업을 해금한다.
2. 첫 수확: 도로와 정수를 연결해 캣닢/목재를 생산한다.
3. 정착: 회관으로 수용 한도를 열고 외부도로 숙소·사료망을 운영해 시민 6마리와 노동력 4를 유지한다.
4. 자립 지구: 인구 10, 행복 72, 사료 비축을 3교대 유지한다.

## 기술·배포
Vite + TypeScript + Canvas 2D. 정적 빌드이며 GitHub Pages 또는 임의 정적 호스트에 배포 가능. 마우스와 터치 지원, localStorage 저장.
