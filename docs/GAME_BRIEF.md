# 냥토피아 공업구역 (Nekopolis Foundry)

## 한 줄 콘셉트
폭우 뒤 버려진 강변을 복구하며 고양이 시민을 위한 식량·주거·위생 생산망과 전력·상하수 인프라를 직접 설계하는 2.5D 공장도시 건설 웹게임.

## 핵심 경험
- 24×18 도시 위에 건물·농장·도로를 배치하고, 전선·수도관은 타일과 시설을 관통하는 직선 segment로 잇는다. 같은 종류 선로는 중간 교차점에서도 자동 접속하며, 겹친 연장은 새 edge만 과금하고 잘못 시공한 선분은 개별 철거·고유 edge 기준 일부 환급할 수 있다.
- 발전소→전선→시설, 취수장→정수장→수도관→시설의 연결 상태가 실제 생산을 결정한다. 수도관은 방향 없는 공용망이며 연결된 정수장이 같은 망 전체에 정수를 공급한다.
- 동쪽 강변 낚시터가 생선을 생산하고 사료 공장이 이를 가공한다. 캣닢은 찻집 행복 기호품이며 가구 공장은 목재를 가공한다.
- 전력·정수·서쪽 외부도로가 연결된 숙소가 고양이를 이주시키며, 실제 인구가 총 노동력을 결정한다.
- 숙소는 LV.1/2/3에서 실제 고양이 +2/+4/+7을 제공하며, 챕터별 최대치 4/8/12/16 안에서 연결된 숙소로 주민이 이주한다. 증축할수록 지도 sprite가 높아진다.
- 회관은 도시 행정·행복의 메인 건물이며 LV.1 주민 사무소→LV.2 행정 회관→LV.3 타워 시청으로 변한다. 도로·전선·수도관을 제외한 모든 건물 업그레이드는 코인·필수 연결·노동 1명을 검사하고 완료 즉시 노동을 복귀시킨다.
- 기반선, 첫 수확, 정착, 자립 지구의 순차 계약으로 다음 건물을 영구 해금한다.
- 시민은 매 교대 사료를 실제 소비하며, 플레이어는 식량·재료·균형 중 노동 우선순위를 선택한다. 정수 인프라를 먼저 배정하고 같은 종류 시설은 교대별 round-robin으로 기회를 나눈다.
- 2.5D와 3D는 같은 아늑한 마을 BGM과 건설·선로·선택·성공·오류·철거 효과음을 사용한다. 첫 사용자 입력 후 시작하며 전체 음향, 효과음만, 음소거를 순환할 수 있다.
- 사료·가구 공방의 부산물을 재활용해 목재로 되돌리고, 캣닢 찻집과 황혼 배송으로 생활 경제를 운영한다.

## 자원
코인, 전력, 물, 생선, 캣닢, 사료, 목재, 가구, 부산물, 모래 원석, 위생 모래, 현재 고양이, 최대 고양이, 가용 노동력, 행복도.

## 건설 요소
도로, 전선, 수도관, 강변 낚시터, 캣닢 밭, 혼합 농장, 발전소, 취수장, 정수장, 산지 모래 원석 채석장, 고양이 모래 공장, 사료 공장, 가구 공방, 재활용 공방, 캣닢 찻집, 숙소, 고양이 회관, 캣타워 광장.

## 화면 방향
중간 명도의 세이지 강변 마을과 따뜻한 시설색을 하나의 제품 언어로 표현한다. 꽃·울타리·나무·밭고랑·돌/흙 기초판이 마을 밀도를 만들고, 짙은 청록 command bar와 하단 건설 dock은 지도를 보조한다. 노랑은 전력, 파랑은 물, 황금색은 목표/생산, 주황은 선택/경고에 사용한다. 시설 경고는 전력·물·노동·도로·원료별 세로 배지로 동시에 보이며, 현재 계약·추천 건설·지도 상태 표식·context inspector가 같은 원인을 설명해야 한다. 주민은 털색·무늬·체형·속도·역할 소품으로 구분한다.

## 진행 계약
1. 강변 기반선: 발전소·취수장·정수망을 가동해 농업을 해금한다.
2. 첫 수확: 도로와 정수를 연결해 캣닢/목재를 생산한다.
3. 깨끗한 보금자리: 강변 낚시터→생선 사료와 산지 원석→위생 모래, 회관·주택을 함께 운영해 시민 6마리를 맞는다.
4. 자립 지구: 인구 10, 행복 72, 사료와 위생 모래 비축을 3교대 유지한다.

## 기술·배포
Vite + TypeScript 기반으로 Canvas 2D 본편과 동일한 `simulation.ts`를 사용하는 Three.js 3D playable surface를 함께 제공한다. 둘은 같은 건설·utility·생산·진행 규칙과 `nekopolis-shared-save` localStorage 상태를 공유한다. 정적 multi-page build이므로 GitHub Pages 또는 임의 정적 호스트에 배포 가능하며 마우스와 터치를 지원한다.
