# 냥토피아 공업구역 (Nekopolis Foundry)

## 한 줄 콘셉트
고양이 시민을 위한 캣닢·사료·가구 생산망과 전력·상수도 인프라를 직접 배치하는 2D 타일 기반 공장도시 건설 웹게임.

## 핵심 경험
- 20×14 타일 도시 위에 건물, 농장, 도로, 전선, 수도관을 배치한다.
- 발전소→전선→시설, 취수장→정수장→수도관→시설의 연결 상태가 실제 생산을 결정한다.
- 캣닢 밭이 원료를 만들고 사료 공장과 가구 공장이 자원을 가공한다.
- 숙소와 고양이 가구가 인구·행복도를 높인다.
- 목표를 달성하며 도시 등급을 올리고 다음 건물을 해금한다.

## 자원
코인, 전력, 물, 캣닢, 사료, 목재, 가구, 인구, 행복도.

## 건설 요소
도로, 전선, 수도관, 캣닢 밭, 혼합 농장, 발전소, 취수장, 정수장, 사료 공장, 가구 공방, 숙소, 캣타워 광장.

## 화면 방향
따뜻한 황혼빛의 2D 아이소메트릭풍 타일, 짙은 남색 패널, 청록 전력선, 파란 수도관, 주황 생산 애니메이션. 실루엣은 명확하고 귀엽되 UI는 공업 시뮬레이션처럼 정밀하게.

## 기술·배포
Vite + TypeScript + Canvas 2D. 정적 빌드이며 GitHub Pages 또는 임의 정적 호스트에 배포 가능. 마우스와 터치 지원, localStorage 저장.
