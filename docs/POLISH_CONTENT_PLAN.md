# 냥토피아 시각·콘텐츠 폴리시 계획

## 목표

이번 패스의 목적은 기능 숫자를 늘리는 것이 아니라, 도시가 살아 움직이고 생산 부산물이 다시 도시 생활로 순환하는 느낌을 만드는 것이다.

## 관찰된 문제

1. 도로가 링크별 둥근 선분으로 렌더링되어 코너·T자·교차 지점에 캡슐 이음새가 보인다.
2. 시설 실루엣과 재질 단계가 적어 줌아웃하면 건물 종류를 색으로만 구분하게 된다.
3. 시뮬레이션 tick과 시각 animation tick이 같아 움직임이 1초 단위로 끊겨 보인다.
4. 인스펙터의 연결·입출력·행동이 같은 밀도로 놓여 현재 문제와 다음 행동이 즉시 읽히지 않는다.
5. 계약 4 이후에는 기존 시설을 더 짓는 것 외에 surplus를 소비할 반복 행동이 부족하다.

## 선택한 통합 루프

### 부산물 순환

- 신규 자원: `SCRAP`
- 사료 공장과 가구 공방의 정상 생산마다 SCRAP +1
- 재활용 공방: SCRAP 3 + 전력 3 + 노동 2 → 목재 2 + 코인 4

기존 가구 생산에서 생긴 부산물이 다시 목재로 돌아가므로 새 자원이 독립 미니게임이 되지 않는다.

### 생활 소비

- 캣닢 찻집: 캣닢 2 + 전력 1 + 정수 1 + 노동 1 → 행복 기여 +6 + 코인 3

캣닢 surplus를 생활 시설이 소비하므로 농업과 행복이 직접 연결된다.

### 반복 배송

- 계약 4에서 황혼 배송 주문 활성화
- 요구: 사료 3 + 가구 1
- 보상: 90코인
- 납품 후 12 tick cooldown
- 플레이어가 직접 납품 버튼을 눌러 surplus를 코인으로 전환

## 시각 구현

- 30fps 이하로 제한한 `requestAnimationFrame` 시각 루프
- 도로 전체를 underlay → body → center highlight → junction plate 순서로 합성
- 노드에서 body를 다시 덮어 round cap 이음새 제거
- 코너를 통과하는 카트는 quadratic interpolation으로 완만하게 이동
- 발전소 연기, 정수장 수면 링, 사료 호퍼 회전, 공방 크레인, 숙소 창문, 회관 깃발, 찻집 증기, 재활용 벨트 애니메이션
- 시설 공통 3단 재질: 접지 그림자, 어두운 flank, 밝은 roof/rim
- 인스펙터: 상태 요약 → 연결 → 입출력 → 시설 행동 순서
- 건설 dock: 더 짧은 카드, 큰 실루엣, 비용·footprint 한 줄, 명확한 선택 상태

## Grok 4.5 기여

사용자 허용에 따라 `xai-oauth/grok-4.5`를 명령 단위 one-shot 아트 디렉터로만 사용했다. 지속 라우팅과 설정은 변경하지 않았다.

- 도로 junction·건물 실루엣·미세 애니메이션 레시피
- 캣닢 찻집, 재활용 공방, 황혼 배송 비콘 콘셉트
- 오리지널 SVG reference sheet: `public/art/grok-content-reference.svg`

SVG는 순수 vector이며 script·외부 이미지·외부 href가 없다. Grok가 넣은 전체 배경 wash는 투명 reference sheet 요구와 달라 제거했다.

## 폐기한 대안

- 새 자원 3–4개와 긴 생산 체인: HUD와 튜토리얼 복잡도만 증가하므로 폐기.
- 별도 퍼즐·NPC 퀘스트: 핵심 도시·생산 루프와 분리되어 폐기.
- 대형 WebP 건물 스프라이트: 현재 zoom·tint·animation과 결합하기 어려워 reference SVG + Canvas 절차적 렌더링을 선택.
- 무작위 재난: 현재 규모에서는 복구 노동보다 불쾌한 리셋으로 느껴질 위험이 커서 폐기.

## 검증 게이트

1. 모든 기존 저장은 신규 SCRAP·배송 상태가 없는 경우 기본값으로 안전하게 이전된다.
2. 기존 27개 테스트가 유지되고 신규 생산·배송·migration 테스트가 추가된다.
3. 도로 직선·코너·T자·교차 fixture에서 center gap과 round stub이 보이지 않는다.
4. 데스크톱과 390px 모바일에서 horizontal overflow가 0이다.
5. 모바일 주요 버튼은 최소 44px이며 inspector와 event card가 건설 dock을 가리지 않는다.
6. `prefers-reduced-motion`에서는 DOM transition을 끄고 Canvas 미세 애니메이션도 정지 상태로 렌더링한다.
7. 콘솔 오류, 실패 요청, 저장/새로고침 상태 손실이 0이다.
8. 새 콘텐츠는 계약 4 이전에는 잠기며, 계약 4에서 기존 surplus를 실제로 소비한다.
