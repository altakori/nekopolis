# 냥토피아 공업구역 — Nekopolis Foundry

고양이 시민을 위한 생산망과 생활 인프라를 설계하는 2.5D 아이소메트릭 공장도시 건설 웹게임입니다.

## 게임 루프

1. 바이오 발전소에서 전력을 생산하고 픽셀을 무시하는 직선 전선을 시설 endpoint에 연결합니다.
2. 강변 취수장→정수장→직선 수도관 순서로 깨끗한 물을 공급합니다.
3. 서쪽 바깥 도시 관문에서 도로를 연결하고 고양이 노동력을 배치해 캣닢과 목재를 생산합니다.
4. 사료 공장과 가구 공방에서 원료를 가공합니다.
5. 외부도로 연결 숙소로 이주·노동력을 늘리고, 고양이 회관을 업그레이드해 최대 고양이 수를 확장합니다.
6. 기반선→첫 수확→정착→자립 지구의 순차 계약을 완료하며 새 시설을 해금합니다.
7. 균형·식량·재료 우선 교대를 선택하고, 사료 소비로 다시 생기는 병목을 관리합니다.

## 주요 기능

- 20×14 Canvas 2.5D 아이소메트릭 도시와 강·초원·식생 지형
- 마우스/터치 드래그 도로 시공과 타일을 관통하는 직선 전선·수도관 segment 시공
- 2×2 다중 타일 시설, 상시 기초판, 4칸 hover·선택 강조
- 고양이 작업자·물류 카트, 발전 터빈, 전력/수류 펄스 애니메이션
- 엄격한 인프라 의미: 도로는 전력·수도를 전달하지 않고 시설도 숨은 전도체가 되지 않음
- 발전 용량, 취수·정수 처리량, 도로 접근, 노동력, 입력 재고를 순서대로 계산하는 생산 시뮬레이션
- 캣닢→사료, 목재→가구 생산과 실제 원료 소비
- 회관 레벨로 결정되는 최대 고양이, 외부도로 연결 숙소가 제공하는 이주·노동력 +2
- 현재 고양이·최대 고양이·가용 노동력의 분리 시뮬레이션과 HUD
- 회관 LV.1–3 업그레이드 및 코인·전력·정수·노동·외부도로 요구조건
- 시설별 전력·정수·도로·노동·원료 병목, 입출력, 실제 처리량 진단
- 2×2 시설의 어느 면에 직선 endpoint가 닿아도 인정되는 footprint 연결 판정
- 전선과 수도관은 같은 위치를 관통·교차할 수 있지만 endpoint와 전도망은 완전히 분리
- 평상시 숨겨지고 발전소·정수장 선택 시에만 glow하는 전력·정수 overlay
- 도로·전선·수도관은 드래그 기하 거리 × 단가를 계산한 뒤 코인 단위로 버림
- 실제 강변에만 배치 가능한 취수장과 원수관/정수관 분리 진단
- 4단계 계약·영구 해금·3교대 자립 유지 목표
- 시민 수에 따른 사료 소비와 균형·식량·재료 노동 우선순위
- 지도 중심 command bar, 임무 overlay, 하단 건설 dock, 선택 시설 context inspector
- localStorage 자동 저장·불러오기와 이전 저장 형식 마이그레이션
- 데스크톱/모바일 반응형 UI
- Grok 제작 오리지널 SVG 타이틀 장식과 고양이 기술자 마스코트

## 실행

```bash
npm ci
npm run dev
```

브라우저에 표시된 로컬 주소를 열어 플레이합니다.

## 조작

- 건설 팔레트 선택 후 좌클릭/터치: 시설 배치
- 도로 선택 후 드래그: 연속 타일 시공
- 전선·수도관 선택 후 드래그: 시작점→끝점 직선 glow와 거리 가격을 확인하고 관통 시공
- 발전소 클릭: 연결된 전력망 glow 표시
- 정수장 클릭: 연결된 원수·정수망 glow 표시
- 설치된 시설 클릭: 인스펙터에서 병목과 처리량 확인
- `Shift` + 클릭: 시설 철거 및 일부 비용 회수
- 가운데/우클릭 드래그 또는 팬 모드: 카메라 이동
- `Ctrl` + 마우스 휠: 지도 확대/축소
- `−` / `＋` 버튼: 지도 확대/축소
- 일반 마우스 휠: 페이지 스크롤

## 상호작용 수치

한 생산 사이클은 3 tick입니다.

- 발전소: 전력 용량 24
- 취수장: 전력 2 → 원수 18
- 정수장: 전력 4 + 원수 → 정수 12
- 캣닢 밭: 물 1 + 노동 1 → 캣닢 3
- 혼합 농장: 전력 1 + 물 2 + 노동 2 → 캣닢 2 + 목재 2
- 사료 공장: 전력 4 + 물 2 + 캣닢 3 + 노동 3 → 사료 2
- 가구 공방: 전력 5 + 목재 3 + 노동 3 → 가구 1
- 숙소: 최대 고양이 +2; 전력·정수·바깥 도시 연속 도로 연결 시 이주 가능, 가용 노동력 +2
- 고양이 회관 LV.1: 최대 고양이 +4
- 회관 LV.2: 120₩ + 전력 여유 4 + 물 여유 2 + 노동 4 → 최대 +4
- 회관 LV.3: 220₩ + 전력 여유 8 + 물 여유 4 + 노동 8 → 최대 +4
- 시민 사료 소비: 생산 사이클마다 `ceil(인구 ÷ 4)`
- 식량 부족: 숙소 보장 인구까지만 이주하며, 그 이상은 행복 하락·인구 감소

## 배포

정적 Vite 빌드이므로 `dist/`를 GitHub Pages, Cloudflare Pages, Netlify 등에 배포할 수 있습니다. `.github/workflows/deploy.yml`은 `main` 푸시 시 GitHub Pages를 빌드·배포합니다. private 저장소의 Pages 사용 가능 여부는 GitHub 계정/조직 플랜 정책에 따릅니다.
