# 냥토피아 공업구역 — Nekopolis Foundry

고양이 시민을 위한 생산망과 생활 인프라를 설계하는 2D 타일 기반 공장도시 건설 웹게임입니다.

## 게임 루프

1. 발전소와 취수장을 짓습니다.
2. 전선과 수도관을 생산 시설까지 직접 연결합니다.
3. 캣닢 밭·혼합 농장에서 캣닢과 목재를 생산합니다.
4. 사료 공장과 가구 공방에서 원료를 가공합니다.
5. 숙소와 캣타워 광장으로 인구와 행복도를 높입니다.
6. 코인·인구·행복·가구 목표를 달성해 도시 지령을 완료합니다.

## 구현된 기능

- 20×14 Canvas 2D 건설 격자와 지형 변주
- 도로, 방향성 전선/수도관, 9종 생산·생활 시설
- 전력/수도 연결망 판정과 시설별 ONLINE/STANDBY 진단
- 캣닢→사료, 목재→가구 생산 및 자원 소비·수익
- 시설별 절차적 2D 아트, 전력/수류 펄스, 연기·농장 디테일
- 건설 팔레트 분류, 비용·설명 툴팁, 단축키
- 전력망/수도망 오버레이, 확대, 선택 시설 관제 패널
- 자원 변화율, 도시 지령, 활동 로그, 일차/속도/일시정지
- localStorage 자동 저장·수동 저장·이전 저장 형식 마이그레이션
- 데스크톱/태블릿/모바일 반응형 UI
- Grok 제작 오리지널 SVG 타이틀 장식과 고양이 기술자 마스코트

## 실행

```bash
npm ci
npm run dev
```

브라우저에 표시된 로컬 주소를 열어 플레이합니다.

## 조작

- 건설 팔레트 선택 후 도시 타일 클릭: 건설
- 이미 설치된 타일 클릭: 시설 관제
- `Shift` + 클릭: 철거 및 일부 비용 회수
- `1`–`9`: 건설 도구 단축 선택
- 마우스 휠 또는 확대 버튼: 도시 확대/전체 보기
- `Esc`: 선택 해제

## 검증

```bash
npm test
npm run typecheck
npm run build
```

## 배포

정적 Vite 빌드이므로 `dist/`를 GitHub Pages, Cloudflare Pages, Netlify 등 정적 호스트에 배포할 수 있습니다. `.github/workflows/deploy.yml`은 `main` 푸시 시 GitHub Pages 빌드·배포를 수행합니다. private 저장소의 GitHub Pages 사용 가능 여부는 GitHub 계정/조직 플랜 정책에 따릅니다.

## 아트

`public/art/cat-mascot.svg`와 `public/art/title-mark.svg`는 이번 프로젝트를 위해 Grok으로 생성한 오리지널 SVG입니다. 외부 이미지나 런타임 웹폰트를 사용하지 않습니다.
