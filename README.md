# 냥토피아 공업구역 — Nekopolis Foundry

고양이 시민을 위한 생산망과 생활 인프라를 설계하는 2.5D 아이소메트릭 공장도시 건설 웹게임입니다.

## 게임 루프

1. 반짝 발전소에서 전기를 만들고 전선을 눌러 드래그해 맑은물 펌프장과 시설에 연결합니다.
2. 맑은물 펌프장이 강물을 바로 깨끗하게 만들며, 맑은 물관이 같은 망의 생활·생산 시설에 물을 공급합니다.
3. 첫 동네의 길·전기·물·냥이 사료·화장실 모래를 먼저 해결한 뒤 냥코인으로 다음 동네를 엽니다.
4. 정착 후 캣닢·목재·가구를 만들고, 마지막에 찻집·광장·행복·배송을 운영합니다.
5. 강변 낚시터에서 생선을 잡고 사료 공장에서 가공하며, 가구 공방과 함께 부산물을 만듭니다.
6. 외부도로·전력·정수가 연결된 숙소로 고양이를 이주시켜 실제 인구 기반 노동력을 늘립니다. 최대 고양이는 챕터 기본치 4/8/12/16에 회관별 보너스를 더합니다.
7. 기반선→첫 수확→정착→자립 지구의 순차 계약을 완료하며 새 시설을 해금합니다.
8. 균형·식량·재료 우선 교대를 선택하고, 재활용 공방으로 부산물을 목재로 되돌립니다.
9. 캣닢 찻집으로 행복·생활 수익을 만들고 황혼 배송 주문에 사료·가구를 납품합니다.

## 주요 기능

- 32×24 논리 타일 위의 2.5D·3D 도시와 강·산·숲·호수·습지·해안 지형
- q1→q2→q3→q4를 냥코인으로 차례로 열며 잠긴 지형은 미리 보여주지 않는 사분면 확장
- 대각선 드래그를 끊김 없는 4방향 계단 도로로 자동 보정하고, 전선·물관은 실제 pointer-down 드래그 중에만 preview
- 2D·3D가 같은 4방향 도로 topology 판정을 공유하며 막다른 길·코너·T자·십자 교차로를 구분한다. 3D는 어두운 기초, 연결형 노면, 외곽 연석, 중앙선, 교차로 hub와 강 위 교각·평행 난간을 입체적으로 표현한다.
- 2×2 다중 타일 시설, 건설·선택 중에만 보이는 footprint guide, 4칸 hover·선택 강조
- 지붕·좌우 벽면·창문·문·굴뚝·탱크를 갖춘 기능별 volumetric 건물과 top/side 두께를 갖춘 도로
- 강 위 road cell을 난간·교각·plank가 있는 raised bridge로 자동 표현
- 도로를 향한 실제 출입구까지 이어지는 입체 진입로와 door→도로 BFS→door 경로를 왕복하며 양 끝에서 하역하는 고양이 화물차
- 시설 간 연결 경로를 따라 이동하고 출입구에서 대기하는 고양이 주민, 이동 중 보행 동작과 역할별 외형
- 시뮬레이션 tick과 분리된 약 30fps 시각 루프, online 상태에 연동된 시설 기계·연기·물 흐름·창문 애니메이션
- 정적 지형/동적 개체 2-layer Canvas, 모바일 DPR 1.5·데스크톱 DPR 2 상한, 실제 FPS 기반 high/balanced/low 자동 품질 조절
- shadow side→side wall→top surface→highlight 순서로 합성되는 raised 도로망과 동일 isometric 축의 건물
- 엄격한 인프라 의미: 도로는 전력·수도를 전달하지 않고 시설도 숨은 전도체가 되지 않음
- 발전 용량, 맑은물 펌프 처리량, 냥이 길 접근, 일손 냥이, 입력 재고를 순서대로 계산하는 생산 시뮬레이션
- 강변 낚시터의 생선→사료, 목재→가구 생산과 실제 원료 소비; 캣닢은 찻집 행복 기호품으로만 사용
- 사료·가구 생산 부산물→재활용 공방→목재 순환, 캣닢 찻집의 행복·코인 생산
- 사료 3 + 가구 1을 90코인으로 교환하는 반복 황혼 배송과 12 tick cooldown
- 챕터별 4/8/12/16 기본 최대 고양이, 회관 LV.1/2/3 한 채당 +4/+6/+8, 숙소의 교대별 이주
- LV.1 단독 주택, LV.2 발코니 빌라, LV.3 고층 아파트로 명확히 구분되는 주거 외형
- 산지 전용 모래 원석 채석장→공정수 기반 고양이 모래 공장→시민 위생 소비·행복도의 신규 생산망
- 장별 현장 이야기, 4장 진행 track, 현재 행동 하나를 강조하는 `NEXT` 안내, 게임 방법 overlay
- 인구 기반 총 노동력, 인프라 우선 배정, 정책별 생산 배정, 동일 시설 round-robin과 `가용고양이/마을고양이` HUD
- 도로·전선·수도관을 제외한 모든 실제 건물의 LV.1–3 업그레이드, 고정 투입 대비 1.0×/1.5×/2.0× 생산·유틸리티·행복 효율
- 회관 LV.1 주민 사무소, LV.2 행정 회관, LV.3 타워 시청으로 구분되는 메인 건물 외형과 행정·행복 효과
- 15종 실제 건물 각각의 LV.1/2/3 고유 실루엣·기능 설비·고양이 건축 모티프
- 곡선 강둑·자갈·갈대·foam과 하류 방향 수면 흐름을 공유하는 2D Canvas·3D shader 강
- 숙소 LV.1–3 증축, 연결 시 실제 고양이 +2/+4/+7, 지도에서 보이는 층수 변화
- 기존 20×14·24×18·6지구 저장을 32×24·4사분면 상태로 보존 migration
- 털색·무늬·체형·속도와 역할 소품이 다른 고양이 주민 5종
- 시설별 반짝 전기·맑은 물·냥이 길·일손 냥이·재료 병목, 입출력, 실제 처리량 진단
- 2×2 시설의 어느 면에 endpoint가 닿거나 선분이 footprint 타일 아래를 지나도 인정되는 연결 판정
- 같은 종류 선분끼리는 shared endpoint뿐 아니라 중간 grid cell의 겹침·교차에서도 junction으로 접속되며, 전선과 수도관 layer는 서로 완전히 분리
- 전력·물·노동·도로·원료 부족을 `⚡!`·`💧!`·`🐈!`·`🛣!`·`📦!` 세로 배지로 동시에 표시
- 평상시 faint trace와 network 전체 예산 안의 흐름 pulse로 가동 상태를 보여주고 전력·정수를 쓰는 모든 시설 선택 시 관련 망과 service terminal이 glow하는 dependency overlay
- 도로·전선·수도관은 드래그 기하 거리 × 단가를 계산한 뒤 코인 단위로 버림
- 실제 강변에만 배치 가능한 취수장과 원수관/정수관 분리 진단
- 4단계 계약·영구 해금·3교대 자립 유지 목표
- 시민 수에 따른 사료 소비와 균형·식량·재료 노동 우선순위
- 지도 중심 command bar, 모바일에서 접고 펼칠 수 있는 임무 overlay, 하단 건설 dock, 선택 시설 context inspector
- localStorage 자동 저장·불러오기와 이전 저장 형식 마이그레이션
- 2D·3D 페이지가 `nekopolis-shared-save` 하나를 함께 사용하는 live State와 기존 `nekopolis-save`/`nekopolis-v2-save` 저장 자동 migration
- 2.5D·3D 공통 CC0 배경 음악과 건설·선로·선택·성공·오류·철거·토글 효과음, 첫 입력 후 재생되는 Web Audio, `전체 음향 → 효과음만 → 음소거` 저장 설정
- 데스크톱/모바일 반응형 UI
- Grok 제작 오리지널 SVG 타이틀 장식, 고양이 기술자 마스코트, 찻집·재활용 공방·배송 비콘 reference sheet

## 실행

```bash
npm ci
npm run dev
```

메인 실행 주소는 `http://127.0.0.1:5173/`이며 `--strictPort`로 고정됩니다. 격리 검증은 `npm run dev:test`로 `http://127.0.0.1:5172/`에서 실행합니다.

페이지 상단의 `3D로 전환 / 입체 도시 체험 ↗`와 `← 2D로 돌아가기`는 클릭 직전 현재 State를 동기 저장한 뒤 다른 페이지로 이동합니다. 두 화면은 `nekopolis-shared-save`를 읽고 쓰므로 grid·utility·resources·stage·tick·paused·speed·work policy가 그대로 이어지며, 카메라 위치 같은 renderer-only 상태는 화면별로 독립입니다. 기존 `nekopolis-save`와 `nekopolis-v2-save`만 남아 있는 브라우저도 처음 진입할 때 canonical save로 자동 migration합니다. canonical save가 있으면 legacy 데이터가 더 최신 tick이어도 덮어쓰지 않습니다.

격리 검증 서버의 `http://127.0.0.1:5172/v2.html`에서 시설 클릭 배치, 도로·전선·수도관 드래그, 네 계약, 전체 생산망, 주거 이주·증축, 시설 진단·철거, 작업 정책, 황혼 배송, 저장·불러오기를 3D로 플레이할 수 있습니다. 5174는 다른 게임용으로 사용합니다.

### 3D 조작

- 좌클릭/터치: 시설 배치 또는 시설 선택
- 좌클릭/터치 드래그: 도로·전선·수도관 연결
- 우클릭 드래그/휠: 카메라 회전·확대
- 화면의 `↶ ⌂ ↷ − ＋`: 모바일 카메라 조작
- `Shift` + 좌클릭 또는 인스펙터 철거 버튼: 철거

## 조작

- 건설 팔레트 선택 후 좌클릭/터치: 시설 배치
- 도로 선택 후 드래그: 연속 타일 시공
- 전선·수도관 선택 후 드래그: 시작점→끝점 직선 glow와 거리 가격을 확인하고 관통 시공
- 발전소 클릭: 연결된 전력망 glow 표시
- 정수장 클릭: 연결된 원수·정수망 glow 표시
- 설치된 시설 클릭: 인스펙터에서 병목과 처리량 확인
- `Shift` + 클릭: 시설 철거 및 일부 비용 회수
- 전선·수도관 선택 후 선로 위 칸 클릭: 해당 칸을 지나는 가장 최근 선분 선택
- `선택 칸 전선/수도관 철거`: 선분 1개 철거 및 시공비 35% 회수
- 3D에서는 발전소·취수장·정수장 같은 시설 위에서도 바로 utility drag 시작 가능; 짧게 탭하면 시설 선택
- 3D canvas focus 후 `←`/`→`: 카메라 회전, `+`/`-`: 확대·축소, `Home`/`0`: 초기화
- 가운데/우클릭 드래그 또는 팬 모드: 카메라 이동
- `Ctrl` + 마우스 휠: 지도 확대/축소
- `−` / `＋` 버튼: 지도 확대/축소
- 일반 마우스 휠: 페이지 스크롤

## 상호작용 수치

한 생산 사이클은 3 tick입니다.

- 발전소: 전력 용량 24
- 취수장: 전력 2 → 원수 18
- 정수장: 전력 4 + 원수 + 노동 1 → 정수 12
- 캣닢 밭: 물 1 + 노동 1 → 캣닢 3
- 혼합 농장: 전력 1 + 물 2 + 노동 2 → 캣닢 2 + 목재 2
- 강변 낚시터: 동쪽 강변 + 도로 + 전력 1 + 노동 2 → 생선 4
- 사료 공장: 전력 4 + 물 2 + 생선 3 + 노동 3 → 사료 3 + 부산물 1
- 가구 공방: 전력 5 + 목재 3 + 노동 3 → 가구 1 + 부산물 1
- 재활용 공방: 전력 3 + 부산물 3 + 노동 2 → 목재 2 + 4₩
- 모래 원석 채석장: 산기슭 + 도로 + 노동 2 → 모래 원석 3
- 고양이 모래 공장: 전력 3 + 정수 2 + 원석 3 + 노동 2 → 위생 모래 3 + 부산물 1
- 캣닢 찻집: 전력 1 + 물 1 + 캣닢 2 + 노동 1 → 행복 +6 + 3₩
- 황혼 배송: 사료 3 + 가구 1 → 90₩, 배송 후 12 tick cooldown
- 숙소 LV.1/2/3: 실제 고양이 +2/+4/+7; 전력·정수·바깥 도시 연속 도로 연결 시 챕터+회관 최대치 안에서 교대마다 이주
- 최대 고양이: CH.1/2/3/4 기본 4/8/12/16 + 각 회관 LV.1/2/3 보너스 +4/+6/+8
- 모든 실제 건물 업그레이드는 코인·필수 연결·가용 노동 1명을 검사하고 순간 완료 직후 노동이 복귀함
- 회관 건설은 MAX +4, LV.2·LV.3 업그레이드는 각각 MAX +2와 행정·행복 효율·외형을 강화함
- 같은 종류의 전선·수도관은 끝점뿐 아니라 중간 교차점에서도 자동 접속; 활성망은 밝게, 공급원에서 고립된 선분은 어둡게 표시. 기존 선로를 일부 따라 연장할 때는 새 edge만 과금. 수도관은 방향 없는 공용망으로, 연결된 정수장이 같은 component 전체에 정수를 공급
- 시민 사료 소비: 생산 사이클마다 `ceil(인구 ÷ 4)`
- 시민 위생 모래 소비: 생산 사이클마다 `ceil(인구 ÷ 6)`; 부족하면 행복도 하락
- 식량 부족: 숙소 보장 인구까지만 이주하며, 그 이상은 행복 하락·인구 감소

## 검증

```bash
npm test
npm run typecheck
npm run build
NEKOPOLIS_URL=http://127.0.0.1:5173 node qa-art/audio-qa.cjs
```

브라우저 QA는 `NEKOPOLIS_URL`로 대상 서버를, `NEKOPOLIS_BROWSER_PATH`로 Chromium 계열 실행 파일을 선택할 수 있습니다. 실행 파일 override가 없으면 Windows의 표준 Chrome 경로가 실제 존재할 때만 사용하고, 그 외 환경에서는 Playwright 기본 브라우저로 fallback합니다.
